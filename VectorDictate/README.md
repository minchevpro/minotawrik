# Vector Dictate

Диктовка голосом в любое приложение на macOS. Нажимаете глобальный хоткей
(по умолчанию **⌥ + Space**) — поверх активного окна появляется маленькая
плавающая панель с микрофоном. Вы диктуете, запись останавливается (Enter,
повторный хоткей, кнопка Stop или автоматически после паузы), аудио
отправляется в OpenAI, текст распознаётся, кладётся в буфер обмена,
сохраняется в историю и автоматически вставляется в активное поле через
имитацию **Cmd+V**.

## Почему именно clipboard + paste

Автовставка реализована как «положить текст в буфер обмена и нажать
Cmd+V», а не как попытка «магически» найти активное текстовое поле через
Accessibility API. Второй подход постоянно ломается в разных приложениях,
веб-вью и фреймворках. Clipboard + synthetic Cmd+V — это то, что умеет
обрабатывать любое приложение, и если вставка по какой-то причине не
сработает (например, фокус не в текстовом поле), текст всё равно остаётся
в буфере обмена и сохраняется в истории — ничего не теряется.

## Требования

- macOS 12 (Monterey) или новее.
- Xcode **Command Line Tools** (полноценный Xcode не обязателен):
  ```
  xcode-select --install
  ```
- API-ключ OpenAI с доступом к `audio/transcriptions`
  (https://platform.openai.com/api-keys).

## Сборка

```bash
cd VectorDictate
./build.sh
```

Скрипт скомпилирует Swift-пакет (`swift build -c release`) и соберёт
полноценный `.app`-бандл — `Vector Dictate.app` — с ad-hoc подписью.
Перетащите его в `/Applications`.

При первом запуске Gatekeeper может предупредить про
«неизвестного разработчика» (приложение не нотарифицировано Apple) —
кликните правой кнопкой по приложению → **Open** → **Open** ещё раз, это
нужно сделать один раз.

## Первый запуск и разрешения

1. **Микрофон** — система спросит разрешение при первом запуске
   (нужно для записи голоса).
2. **Universal Access (Accessibility)** — приложение покажет подсказку и
   предложит открыть Системные настройки → Конфиденциальность и
   безопасность → Универсальный доступ, добавьте туда Vector Dictate.
   Это разрешение нужно для:
   - имитации нажатия Cmd+V (автовставка),
   - перехвата клавиш Enter/Esc во время записи, чтобы они не «утекали»
     как обычный ввод в активное поле.

   Без этого разрешения диктовка всё равно полностью работает: текст
   копируется в буфер обмена и сохраняется в истории — просто без
   автоматической вставки, и Enter/Esc будут также проходить как обычный
   ввод в текущее приложение.

3. Откройте иконку в строке меню (значок микрофона) → **Настройки…** и
   вставьте свой OpenAI API-ключ. Ключ хранится в Keychain, а не в
   обычных файлах настроек.

## Использование

- Нажмите хоткей (по умолчанию **⌥ + Space**) в любом приложении —
  появится плавающая панель, начнётся запись.
- Говорите. Запись останавливается любым из способов:
  - нажать **Enter**,
  - повторно нажать хоткей,
  - кликнуть **Stop** на панели,
  - **тишина** дольше заданного порога (настраивается в Настройках,
    по умолчанию ~1.6 c).
  - **Esc** — отменить запись без отправки в OpenAI.
- Через секунду-две текст распознан, автоматически вставлен в то место,
  где стоял курсор, и сохранён в истории.
- **История…** в меню — поиск, копирование, повторная вставка и удаление
  прошлых записей.

## Настройки

Открываются через иконку в строке меню → **Настройки…**:

- **Хоткей** — кликните на поле и нажмите новую комбинацию.
- **Автовставка** — можно отключить, если нужен только буфер обмена.
- **OpenAI** — API-ключ, модель (`whisper-1`, `gpt-4o-transcribe`,
  `gpt-4o-mini-transcribe`), язык (ISO-639-1 код или пусто для
  автоопределения).
- **Автостоп по тишине** — порог громкости (dB), длительность паузы,
  максимальная длительность записи (защита от «зависшей» записи).

## Структура проекта

```
VectorDictate/
  Package.swift                  — Swift Package Manager манифест
  build.sh                       — сборка + упаковка в .app
  Resources/Info.plist           — метаданные бандла (LSUIElement, разрешения)
  Sources/VectorDictate/
    main.swift                   — точка входа
    AppDelegate.swift            — жизненный цикл приложения, разрешения
    StatusBarController.swift    — иконка и меню в строке меню
    HotkeyManager.swift          — глобальный хоткей (Carbon RegisterEventHotKey)
    KeyInterceptor.swift         — перехват Enter/Esc во время записи
    AudioRecorder.swift          — запись звука + детектор тишины
    OpenAITranscriptionService.swift — загрузка аудио в OpenAI
    PasteSimulator.swift         — буфер обмена + имитация Cmd+V
    DictationPanelController.swift / DictationPanelView.swift — плавающая панель
    HistoryStore.swift / HistoryView.swift — история диктовок
    SettingsView.swift           — окно настроек
    KeychainHelper.swift         — хранение API-ключа
    PermissionsManager.swift     — онбординг разрешений
    Models.swift                 — модели данных и AppSettings
```

## Приватность

- Аудио отправляется напрямую в OpenAI API по HTTPS и нигде больше не
  хранится — временный файл записи удаляется сразу после получения
  ответа (или в случае ошибки).
- API-ключ хранится в Keychain.
- История текстов хранится локально в
  `~/Library/Application Support/VectorDictate/history.json` и никуда не
  отправляется.

## Известные ограничения

- Сборка и проверка этого проекта производились в окружении без Xcode/
  macOS (Swift-код писался и проверялся вручную на синтаксис и логику,
  но не компилировался локально через `swiftc`/Xcode, так как
  AppKit/Carbon/AVFoundation доступны только на macOS). Перед первым
  запуском на реальном Mac рекомендуется собрать через `./build.sh` и
  проверить базовый сценарий: хоткей → запись → распознавание →
  вставка.
- Приложение не песочница (sandboxed) и не нотарифицировано Apple,
  так как ему требуется системный доступ Accessibility для имитации
  Cmd+V — это несовместимо с App Sandbox/Mac App Store.
